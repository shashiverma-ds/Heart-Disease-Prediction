# Heart Disease Prediction
This project predicts the likelihood of heart disease in patient based on medical features using Machine Learning.
## Model performance
** Algorithm:** Random Forest Classifier
** Accuracy:** 87.5%
## Datasets & Features
The datasets includes key health metrics such as Age, Sex, Chest Pain Type, Resting BP, Cholesterol, Fasting Blood Sugar, and Max HR.
## Tech Stack
* Python
* Pandas & seaborn
* Matplotlib & seaborn
* Scikit-Learn
